# 全項目の動作確認用フォーム

確認ページ： https://fam-security-wp.test/form-check/

管理画面の「メールフォーム」から「全項目チェック用フォーム」を編集できます。既存の問い合わせページとは別のフォームです。

## 入力とボタン

1. ページを開きます。空欄の状態で確認ボタンが押せないことを確認します。
2. お名前に「確認 太郎」を入れます。
3. メールアドレスに自分で受信確認できるアドレスを入れます。
4. 連絡方法に「メール」を選びます。
5. ご相談内容に10文字以上入力します。
6. 2つの同意欄を確認してチェックします。
7. 確認ボタンが押せることを確認します。
8. 任意の形式検証欄へ不正な値を入れ、ボタンが無効になることを確認します。
9. 正しい値に直し、ボタンが有効になることを確認します。

| 確認する欄 | 正しい入力例 | 不正な入力例 |
| --- | --- | --- |
| 電話番号 | 0312345678 | abc |
| URL | https://example.com/ | example |
| ひらがな | やまだたろう | ヤマダ |
| カタカナ | ヤマダタロウ | やまだ |
| ひらがな or カタカナ | ヤマダたろう | 山田 |
| 半角英字 | ABCxyz | ABC1 |
| 半角英数字 | ABC123 | ＡＢＣ |
| 半角数字 | 123 | １２３ |
| 日付 | 2024-02-29 | 2025-02-29 |
| 文字数（2〜5文字） | あいう | あ |
| 郵便番号 | 100-0001 | 123 |

任意欄を空に戻すと形式エラーは解除されます。条件付き必須は連絡方法を「電話」にすると専用欄が必須になります。既存の問い合わせフォームの電話番号は任意のままです。

## 住所・選択・添付

1. 住所1行用の郵便番号に `1000001` を入力します。
2. 東京都千代田区千代田が住所へ入ることを確認します。全角数字・全角ハイフンの `１００－０００１` でも自動入力され、欄を離れると `100-0001` に整形されることを確認します。
3. 分割用郵便番号にも `1000001` を入れます。
4. 都道府県と住所1が埋まり、住所2は手入力できることを確認します。
5. 住所を手直しし、郵便番号を変えても手直しが残ることを確認します。
6. 分割用郵便番号に `0040000` を入れ、複数候補を選べることを確認します。
7. 地域、ラジオ、複数選択を操作します。
8. 添付に1MB以内のPNG・JPEG・PDFを選びます。許可外の拡張子や上限超過ではボタンが無効になります。
9. 確認画面へ進み、選択肢のラベル・添付名・同意表示が正しいことを確認します。
10. 戻るボタンで値が残り、入力画面を再読み込みすると初期化されることを確認します。

## メールと完了

通知先はこのローカルサイトの管理者メールアドレスです。管理画面の通知メール欄で送信先を確認・変更してください。自動返信先は入力したメールアドレスです。既存サイトのSMTP設定で送信します。

1. 宛先を確認します。
2. フォームを入力し、確認画面で「送信する」を押します。
3. 完了画面になることを確認します。
4. 自動返信と通知の件名・本文を確認します。
5. 本文に全項目がラベル付きで並び、同意欄が「同意する」になっていることを確認します。

開発側のブラウザー確認ではメールを送信していません。実送信・受信はこの手順で確認してください。


## 開発側で確認済みのこと

- 全27項目を表示。必須欄が揃うとボタンが有効になり、各形式の不正入力で無効になることを実ブラウザーで確認。
- ひらがな・カタカナ・両方・英字・英数字・数字・日付・文字数・郵便番号の正誤と、条件付き必須の切り替えを確認。
- 住所1行と分割住所の自動入力、確認画面への遷移、戻った時のボタン有効化、再読み込みでの初期化を確認。
- 地域選択の矢印は元デザインと同じ右20px、高さ50%、7px、translateY(-70%) rotate(45deg)で配置。説明・エラー領域を含めず、selectだけを基準にする。
- メール初期文面の試験6項目、PHP回帰試験、PHP／JS共通条件51件、HTTP結合106項目とビルドが成功。
- 実メールの送信・受信は未実施。狭い画面の確認はブラウザーの幅変更が反映されず未完了。
