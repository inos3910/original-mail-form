# 郵便番号と住所を追加する

フォーム編集画面の「入力欄を追加」から、次の3種類を選べます。

| ボタン | 追加される項目 |
| --- | --- |
| 郵便番号 | 郵便番号1欄。7桁の形式をPHP・JSで検証 |
| 郵便番号＋住所（1行） | 郵便番号、住所。住所は都道府県から町域まで自動入力 |
| 郵便番号＋住所（分割） | 郵便番号、都道府県、住所1（市区町村・町域）、住所2（番地・マンション名等） |

1. 管理画面で編集するフォームを開きます。
2. 「郵便番号＋住所（1行）」または「郵便番号＋住所（分割）」を押します。
3. 「変更を保存」を押します。
4. 設置済みフォームを開きます。
5. 郵便番号に `1000001` を入力します。住所が「東京都千代田区千代田」になれば成功です。
6. 番地・建物名を手入力します。

各セットは任意入力で追加されます。必要な項目の「必須にする」をONにすれば、PHPとJSで必須になります。キーは既存項目と重複しないよう作成するため、同じセットを複数追加できます。分割セットの住所1には市区町村と町域まで入ります。住所2には番地・建物名などを入れます。

既存項目も、郵便番号項目の「郵便番号から住所を自動入力」で入力先を選ぶと自動入力できます。住所1行の入力先と、都道府県・住所1の入力先は同時に使いません。連携した住所項目を削除する際は、郵便番号側の入力先を解除するか変更してから保存してください。

全角の数字は半角にし、フォーカスを外すと123-4567形式に整えます。複数の住所に該当する番号では候補から選択します。手入力済みの住所は上書きしません。自動入力した値をまだ手直ししていなければ、郵便番号の変更に合わせて更新します。入力済み住所を自動入力し直す場合は、対象の住所を空欄にしてください。

該当する住所がない場合やデータの読込に失敗した場合も、住所は手入力できます。番地や建物名は自動入力されません。

## データと通信先

[日本郵便のUTF-8データ](https://www.post.japanpost.jp/service/search/zipcode/download/utf-zip.html)を同梱しています。2026-09-30更新分、120720郵便番号。データは先頭3桁ごとに948ファイルへ分割し、必要なファイルだけこのサイトから読み込みます。初期状態はプラグイン同梱データ、設定画面から更新した後はアップロード領域のデータを使用します。利用者の郵便番号を外部APIへ送信しません。入力した住所や郵便番号を検索サービス側へ保存する処理もありません。

町域を特定しない注記や括弧内の番地条件は自動入力の住所から取り除きます。日本郵便の町域データには、大口事業所専用の郵便番号は含まれません。住所は必ず本人が確認・補完します。

## 管理画面からデータを更新する

1. 管理画面の「メールフォーム」→「設定」を開きます。
2. 「郵便番号からの住所自動入力」の現在の件数と更新日を確認します。
3. 「郵便番号データを更新」を押します。
4. 処理が終わるまで待ちます。
5. 「郵便番号データを更新しました」または「すでに最新です」が表示されたことを確認します。

ボタンを押したときだけ、日本郵便の公式サイトから全国ZIPを取得します。毎月の自動実行やcron設定はありません。同じデータの場合は再生成せず、確認日時だけ更新します。取得後の日時は公式の公表日ではなく、このサイトがデータを取得した日時です。

更新データは `wp-content/uploads/omf-postal/` に保存します。プラグインの更新で消えません。ZIPの内容と全国分の件数を検証し、全ファイルの生成・保存が成功してから参照先を切り替えます。失敗時は既存データを維持します。PHPのZipArchive、HTTPSでの外向き通信、アップロード先への書き込み権限が必要です。問題があると画面に理由が表示されます。

更新前に開いたフォームも住所検索を続けられるよう、古いデータは7日間保持し、その後の更新時に削除します。バックアップにはアップロード領域も含めてください。ページキャッシュがある場合は、更新後にフォームのページキャッシュを削除すると最新データへ切り替わります。

## 開発者向け：同梱データの更新

日本郵便のページから最新のUTF-8 ZIPを取得し、プラグイン開発元で次を実行します。年月日は公式ページに表示されたデータ更新日です。

```sh
python3 tools/build-postal-data.py /path/to/utf_ken_all.zip --date YYYY-MM-DD
node tests/address-presets.mjs
```

生成したassets/postalをプラグイン更新に含めます。manifest.jsonに出典・更新日・元ZIPのSHA-256・件数を記録します。古い月のデータを自動更新するcronは設けていません。
