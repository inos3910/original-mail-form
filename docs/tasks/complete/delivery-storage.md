# OMF-007 永続的な送信待ち・結果管理

## 作成日

2026-09-26

## ステータス

完了（状態の正本は [TASK.md](../TASK.md)）

## 概要

セッション終了後も未送信内容と各メールの結果を管理する。

優先度: P1 / 依存: OMF-005, OMF-006

## 背景・目的

既存の自由なコード方式を維持し、管理者の編集負担と送信時の待ち時間を改善する。既存修正の検証状況は [レビュー対応記録](../../review/complete/review-fixes-20260926.md) を参照する。

## 要件

受付ID、自動返信/通知別状態、試行回数、失敗理由、排他制御を永続化する。成功したメールは再送しない。SMTP受理後に結果保存が失敗した場合は結果不明として扱う。管理画面で状態確認・再試行できるようにする。添付は処理完了または保持期限まで非公開で保管する。

## 非対象

- 他タスクの機能実装、GA4ランキングの変更。
- 本番反映、merge、push、リリース公開。

## 実装計画

1. 台帳・依存タスク・関連実装とGit差分を確認する。
2. 下記の確認事項を解消し、API・互換性・異常系を確定する。
3. 対象機能を既存設計に合わせて実装する。
4. 正常系・異常系と依存機能の回帰確認を実行する。
5. 記録・台帳を更新し、進捗HTMLを再生成する。

DB保存OFFでも非同期の一時永続保存は必須と明示する。個人情報の消去・保持期間と待機ジョブを整合させる。自動再試行上限はOMF-006で決定。
