# OMF-017 エクスポート・インポート画面の整理

- 起票日：2026-10-16
- ブランチ：`feature/port-ui`（develop から作成）
- 目的：「設定を含める」「フォームは含めない」「秘密情報も含める」の意味がわかりにくいため、画面と書き出し単位を整理する

## 決定事項（2026-10-16 利用者確認済み）

### 書き出し画面

1. 書き出す範囲（カード型の3択）
   - 丸ごとすべて：全フォームの全項目＋プラグイン共通の設定
   - フォームを選ぶ：フォーム一覧と項目の選択を開く
   - 共通設定だけ：「一般」「reCAPTCHA」タブの設定だけ
2. 「フォームを選ぶ」の時：左にフォーム一覧（全選択つき）、右に書き出す項目。狭い画面では縦積み。項目の選択は選んだ全フォームに共通。下に「プラグイン共通の設定も含める」（初期は外す）
3. ボタンの上に書き出す内容の要約を1行で出し、何も選んでいない時はボタンを押せない

| 項目（parts） | 中身 |
| --- | --- |
| フォーム情報 `info` | タイトル・公開状態・入力方式・管理画面方式の項目定義（項目ごとの入力チェックを含む） |
| バリデーション `validation` | コード方式のバリデーション設定・フロント側の入力チェック設定 |
| 画面設定 `screen` | 入力・確認・完了画面、確認画面を飛ばす設定、完了メッセージ、表示条件、連携ページ |
| メール文面 `mail` | 通知メール・自動返信メール（宛先・送信者・件名・本文・自動返信の停止） |
| その他の設定 `other` | reCAPTCHA／Turnstile の使用、データベース保存、送信方法、Slack のチャンネル、Googleスプレッドシート連携、上記に当てはまらない `cf_omf_` メタ |

### 書き出さないもの

- 送信データ、メールIDの連番、秘密情報すべて（reCAPTCHA・Turnstile・Google連携のキー、Slack Webhook URL）。「秘密情報も含める」は廃止
- 古いファイルに秘密情報が入っていても取り込みでは無視し、取り込み先の値を残して警告する

### 取り込み

- ファイルに含まれる項目だけを更新する。「ファイルに無い `cf_omf_` メタを削除」も含まれる項目の範囲に限る
- タイトル・公開状態は `info` がある時だけ、表示条件・連携ページは `screen` がある時だけ更新
- `parts` の無い既存ファイルは全項目入りとして扱う（形式バージョンは 1 のまま）
- 確認画面にフォームごとの取り込む項目を表示。取り込み先に無いフォームは含まれる項目だけで作成し、残りが未設定になる旨を表示

## UI再調整（2026-10-16）

- 外枠はエクスポート／インポートの操作単位だけにし、選択欄の枠は削除。項目のまとまりは見出し・区切り・余白で示す。
- `fieldset` 内の `legend` は Grid の gap が効かないため、見出し下に8pxの余白を明示。グループ間は24px、入力欄とボタンは左揃えに統一。
- 書き出し対象外の情報と取り込みルールを開閉式の補足へ移動。取り込みの実行前に確認画面があることは常時表示する。
- ファイル選択欄の最小幅によるモバイルのはみ出しを修正。確認・結果画面も共通CSSで操作ボタンの左揃えを適用。
- 開発元の変更をローカル `corp-oji` のプラグインへ反映。画面確認は利用者指定の `http://localhost/corp-oji/` で実施し、検証サイト・DB・サーバーは新規作成しない。
- 確認：375／768／1024／1440pxでページ横幅のはみ出しなし。フォーム未選択時のボタン無効化、全選択時の要約更新を確認。既存 `tests/port-ui.php` と変更PHPの構文確認が通過。
- 未実施：実ファイルの取り込み実行、および取り込み確認・結果画面の実表示（既存データを更新する操作は行っていない）。
