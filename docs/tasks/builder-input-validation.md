# 管理項目の一括設定・共通バリデーションと表示拡張

## 作成日

2026-09-30

## ステータス

## 概要・背景

実サイトへの導入で判明した、選択肢入力の手間とPHP/JSの検証条件の不一致を解消する。通常はrender_formの1行で完結し、複雑なデザインだけ任意のPHP項目テンプレートを使う。

## 要件

- 選択肢を1行1件で一括追加し、47都道府県を用意する。
- 同意欄に規約本文と安全なリンクを表示できる。
- 管理画面で文字数・形式・条件付き必須を指定し、PHPとJSで同じ条件を使う。
- JSはフォームごとにON/OFF。OFFでもPHPで検証する。
- 項目順序を管理画面から維持する任意PHPテンプレートを提供する。
- 確認・完了で見出しを切り替え、入力時の電話案内を隠す。

## 非対象

本番反映、実宛先への試験送信、merge/push。

## 実装計画

共通定義→管理UI→レンダラー/JS→隔離検証→ローカル反映→利用者確認。

形式はPHPとJSで使える共通の正規表現に限定する。ファイル内容やCAPTCHA等はサーバーで検証する。外部メールは隔離試験で遮断する。
