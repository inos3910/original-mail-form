# フォーム・メールの設定が表示されない不具合

WordPressの表示オプションで必須メタボックスが非表示になっていると、タブを選んでも内容が空になり、その他の設定だけを編集できる状態になる。

`OMF_Form_Builder::visible_editor_boxes()` を `hidden_meta_boxes` に登録し、フォーム編集画面の項目編集・画面設定・バリデーション・自動返信・通知メールを非表示対象から除外した。タブへ移すメタボックスは過去の非表示・折りたたみクラスを解除する。フォーム設定やユーザーの表示オプションの保存値自体は変更しない。

検証サイト：`/Users/Yosuke/Herd/fam-security-wp`、`https://fam-security-wp.test`、DB `fam_security`。フォーム76で3つのタブを切り替え、項目・画面設定、両メール、その他の設定を表示できる。メールや項目の設定は保存していない。

Webpackビルド、PHP構文、`tests/form-builder.php` の21項目が成功。追加した3項目は非表示履歴からの復帰、他の投稿タイプへの非干渉、フォーム一覧への非干渉を確認する。設置済みプラグインにも同じ修正を加え、設置側の既存ソースからタブを含むJSだけを再ビルドした。
